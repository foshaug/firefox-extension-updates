# Firefox extension updates

Public update feed and Mozilla-signed packages for Firefox extensions. Source is maintained separately in a private repository.

The latest signed X GIF Downloader release is **1.1.1**, with regular X video support and automatic update checks. [Download the signed XPI](packages/x-gif-downloader-1.1.1.xpi). Install it through `about:addons` → gear icon → **Install Add-on From File…**.

Copies of 1.0.1 and 1.1.0 need this manual installation once because they do not include the update feed URL. Future signed versions published to this feed can update automatically. Firefox does not downgrade to older entries.

In Firefox, open `about:addons`, select the extension, and keep automatic updates enabled. Use the gear menu’s **Check for Updates** to check immediately.
